# Shellme Importer
[![Foundry-12]][Foundry URL] ![Version]

Модуль для Foundry VTT 12, импортирующий JSON персонажа [ShellMe](https://shellme.ru/characters) в Cyberpunk RED - Core.

## Использование

1. Заполните лист на сайте
2. Нажмите в боковой панели справа "Сохранить"
3. На Фаундри в листе персонажа-вампира нажмите "Shellme"
4. Выберите скачанный файл
